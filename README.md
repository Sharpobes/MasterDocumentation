# MasterDocumentation

MasterDocumentation — переносимое настольное WPF-приложение для ведения локальной древовидной базы документации. Оно работает без сервера, WebView2, установки .NET и прав администратора.

## Возможности

- папки и документы с произвольной вложенностью, переименованием, удалением и перемещением drag-and-drop;
- вкладки открытых документов, автосохранение и поиск по названию/тексту;
- редактор WPF `RichTextBox`: начертание, шрифты, размеры, цвета, выравнивание, списки, отступы, заголовки, ссылки, таблицы и изображения;
- изменение размера выбранного изображения, Undo/Redo, буфер обмена и стандартные горячие клавиши;
- светлая/тёмная тема, сохранение положения и размера окна;
- ручные и ежедневные автоматические ZIP-копии, проверяемое восстановление и экспорт в папку.

## Архитектура

Проект использует MVVM и разделён на `Models`, `ViewModels`, `Views`, `Services`, `Storage` и `Utilities`. `MainViewModel` управляет состоянием дерева и вкладок, `DatabaseService` изолирует SQLite, `BackupService` отвечает за ZIP и экспорт. Сложные взаимодействия с `RichTextBox`, диалогами и drag-and-drop находятся в code-behind представления, поскольку это поведение UI.

## Данные

Все данные находятся рядом с EXE:

```text
Data/
  master-documentation.db
  Assets/
  Logs/
  Backups/
```

Структура, метаданные, извлечённый текст и настройки хранятся в SQLite. Форматированное содержимое хранится в базе как WPF XamlPackage, поэтому восстанавливаются таблицы, ссылки и встроенные изображения. При вставке исходный файл изображения копируется в `Data/Assets` с уникальным именем; абсолютный исходный путь не сохраняется.

> Папка приложения должна быть доступна текущему пользователю на запись. Не размещайте переносимую копию в `Program Files`.

## Сборка

Требуется Windows и .NET SDK 10:

```powershell
dotnet restore
dotnet build -c Debug
dotnet build -c Release
dotnet publish -c Release -r win-x64 --self-contained true -o publish\win-x64
```

Проект настроен на self-contained single-file публикацию. Готовый файл: `publish\win-x64\MasterDocumentation.exe`.

## Первый запуск

Запустите `MasterDocumentation.exe`. Приложение автоматически создаст `Data` и пример «Начало работы». Для переноса копируйте **всю** папку публикации вместе с `Data`.

## Резервные копии

- **Файл → Резервная копия** создаёт ZIP в `Data\Backups`.
- **Файл → Восстановить** проверяет ZIP, создаёт страховочную копию текущих данных, заменяет базу и предлагает перезапуск.
- **Файл → Экспорт в папку** создаёт отдельную переносимую папку с БД и Assets.
- Автокопия создаётся не чаще раза в сутки; сохраняются последние 10 автоматических архивов.

## Известные ограничения

- Только Windows x64; WPF не является кроссплатформенным.
- Поиск использует SQLite `LIKE`, а не морфологический FTS-анализ русского языка.
- Изменение размера изображения выполняется кнопками панели свойств после установки курсора рядом с изображением.
- Внешние ссылки открываются системным браузером; предварительный просмотр веб-страниц не реализован.
- Single-file self-contained приложение при первом старте может извлечь нативную SQLite-библиотеку во временный каталог .NET; пользовательские данные при этом всегда остаются рядом с EXE.
