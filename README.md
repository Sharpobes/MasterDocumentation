# MasterDocumentation

MasterDocumentation — переносимое WPF-приложение для локальной древовидной документации. Сервер, учётная запись и облако не нужны; документы, версии, настройки и вложения остаются на компьютере пользователя.

## Реализовано

- разделы, папки и документы с произвольной вложенностью, уникальными именами, drag-and-drop, корзиной, избранным и недавними файлами;
- несколько вкладок, автоматическое сохранение, аварийные черновики, история версий с закреплением и сравнением текста;
- TipTap-редактор: заголовки H1–H6, начертания, шрифты и размеры, цвета, выравнивание, списки и чек-листы, цитаты, спойлеры, ссылки, изображения, таблицы и блоки кода;
- расширенная типографика: межсимвольный и межстрочный интервалы, интервалы абзаца, первая строка, левые/правые отступы, LTR/RTL и форматирование по образцу;
- маркированные, цифровые, буквенные и римские списки с задаваемым начальным номером;
- блоки документа: цветные callout-примечания, сворачиваемые секции, разрывы страниц, формулы KaTeX и Mermaid-диаграммы;
- служебные элементы документа: дата и время, именованные якоря и очищаемые безопасные HTML-блоки без скриптов и удалённых ресурсов;
- автоматическое определение языка и подсветка кода через lowlight/highlight.js;
- живая иерархическая структура документа и оглавление;
- вставка изображений из буфера обмена и перетаскивание файлов;
- редактирование выбранных изображений: масштаб, поворот, выравнивание, alt-текст, замена, открытие оригинала и удаление;
- вложения с SHA-256-дедупликацией, теги, статусы и полнотекстовый поиск SQLite FTS5;
- шаблоны документов, импорт TXT/Markdown/HTML/RTF/DOCX и PDF как вложения;
- экспорт в PDF, DOCX, HTML, Markdown и TXT, системная печать содержимого WebView2;
- резервные копии с контрольными суммами и опциональным AES-256-GCM-шифрованием;
- встроенная страница настроек, настраиваемые горячие клавиши и проверяемый перенос папки данных.

## Данные

По умолчанию данные находятся рядом с EXE:

```text
Data/
  master-documentation.db
  settings.json
  Assets/
  Backups/
  Exports/
  Logs/
  Temp/Drafts/
```

Путь можно изменить в `Настройки → Хранение`. Перед переключением приложение копирует данные во временную папку и выполняет `PRAGMA integrity_check`; старое хранилище автоматически не удаляется. Выбранный путь записывается в локальный `data-location.txt`, который не следует добавлять в Git.

Основное rich-text содержимое хранится как TipTap JSON и HTML. Простой текст хранится отдельно для FTS5. Файлы в `Assets` именуются по SHA-256, поэтому одинаковое содержимое физически не дублируется.

## Сборка

Требуются Windows x64, Node.js/npm для пересборки редактора и .NET 8 SDK:

```powershell
cd src\MasterDocumentation.Editor\web
npm ci
npm run build
cd ..\..\..
dotnet restore MasterDocumentation.sln
dotnet build MasterDocumentation.sln -c Release
dotnet test MasterDocumentation.sln -c Release
dotnet publish MasterDocumentation.csproj -c Release -r win-x64 --self-contained true -o publish\win-x64
```

`node_modules` — локальный кэш npm-зависимостей. Он большой, восстанавливается командой `npm ci` из `package-lock.json` и поэтому исключён из Git. В репозиторий входят исходник редактора и собранные файлы `web/dist`.

Публикация self-contained включает .NET. Для rich-text редактора требуется Microsoft Edge WebView2 Runtime: приложение использует `FixedRuntime` рядом с EXE, если он поставляется, иначе системный Evergreen Runtime.

## Известные ограничения

- только Windows x64;
- импорт DOCX пока переносит текст и стили заголовков, но не все сложные объекты Word;
- PDF импортируется как локальное вложение, распознавание/редактирование PDF не выполняется;
- PDF-экспорт сохраняет текст и разбиение на страницы, но не полностью повторяет CSS-вёрстку редактора;
- расширенные операции обработки изображений (кадрирование и фильтры) ещё не реализованы;
- полная русско-английская локализация ресурсов и полноценная светлая тема требуют отдельного прохода.
