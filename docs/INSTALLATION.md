# Установка и обновление MasterDocumentation

## Выбор версии

Откройте [страницу всех релизов](https://github.com/Sharpobes/MasterDocumentation/releases). GitHub хранит каждую опубликованную версию отдельно, поэтому можно скачать как последнюю, так и предыдущую сборку.

Для версии 1.0 используйте:

- [portable ZIP v1.0.0](https://github.com/Sharpobes/MasterDocumentation/releases/download/v1.0.0/MasterDocumentation-v1.0.0-win-x64.zip);
- [SHA-256 v1.0.0](https://github.com/Sharpobes/MasterDocumentation/releases/download/v1.0.0/MasterDocumentation-v1.0.0-win-x64.zip.sha256).

## Установка portable-версии

1. Скачайте ZIP нужной версии из блока **Assets** на странице релиза.
2. Создайте локальную папку, например `D:\Apps\MasterDocumentation`.
3. Распакуйте в неё **весь** архив с сохранением структуры каталогов.
4. Проверьте, что рядом с `MasterDocumentation.exe` находятся папки `Editor` и `WebView2`.
5. Запустите `MasterDocumentation.exe`.
6. В мастере первого запуска выберите язык, тему, папку данных и режим резервного копирования.

Установка в `Program Files` не рекомендуется для portable-режима: обычному пользователю может не хватить прав на запись рядом с EXE. Если приложение обнаружит недоступную папку, оно предложит выбрать другое хранилище.

## Предупреждение Windows SmartScreen

Пока EXE не подписан коммерческим сертификатом, Windows может показать SmartScreen:

1. убедитесь, что архив скачан со страницы `Sharpobes/MasterDocumentation`;
2. проверьте SHA-256;
3. нажмите **Подробнее**;
4. нажмите **Выполнить в любом случае**.

## Проверка SHA-256

В PowerShell выполните:

```powershell
Get-FileHash .\MasterDocumentation-v1.0.0-win-x64.zip -Algorithm SHA256
Get-Content .\MasterDocumentation-v1.0.0-win-x64.zip.sha256
```

Хеши должны совпасть. Файл `.sha256` создаётся тем же workflow, который собирает релиз.

## Первый запуск

По умолчанию приложение создаёт `Data` рядом с EXE. В ней находятся база SQLite, настройки, вложения, резервные копии, экспортированные документы, журналы и аварийные черновики. Демонстрационные документы автоматически не создаются.

Если нужна отдельная папка, выберите её в мастере или позднее в `Настройки → Хранение → Изменить папку`. Перенос выполняется через временную копию с последующей проверкой `PRAGMA integrity_check`.

## Обновление без потери данных

1. В приложении создайте резервную копию: `Настройки → Хранение → Создать резервную копию`.
2. Закройте MasterDocumentation.
3. Скачайте и распакуйте новую версию в новую папку.
4. Скопируйте старую папку `Data` и файл `data-location.txt` в новую папку приложения. Если использовалось внешнее хранилище, достаточно перенести `data-location.txt`.
5. Запустите новую версию и проверьте документы.
6. Старую папку удаляйте только после проверки.

Не копируйте `Data` при работающем приложении: база может находиться в режиме WAL.

## Полное удаление

MasterDocumentation не регистрирует системные службы и не требует деинсталлятора. Для удаления:

1. создайте резервную копию, если данные нужны;
2. закройте приложение;
3. удалите папку приложения;
4. удалите внешнюю папку данных, если выбирали её отдельно.

## Восстановление резервной копии

1. Откройте стартовую страницу или меню приложения.
2. Нажмите **Восстановить резервную копию**.
3. Выберите файл `.mdbackup`.
4. Если копия зашифрована, введите пароль.
5. Подтвердите замену текущих данных.

Перед заменой приложение создаёт страховочную копию текущего хранилища и проверяет контрольные суммы архива и целостность SQLite.

## Если приложение не запускается

- распакуйте архив полностью, не запускайте EXE из ZIP;
- убедитесь, что папки `Editor` и `WebView2` находятся рядом с EXE;
- переместите приложение из сетевой/UNC-папки на локальный диск — Fixed Version WebView2 не поддерживает запуск из сетевого расположения;
- проверьте наличие свободного места и прав на запись;
- откройте `Data\Logs` и приложите последний журнал к GitHub Issue.
